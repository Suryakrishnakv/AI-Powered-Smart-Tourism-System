About Kerala Smart Tourism System

Project Overview

This system is an intelligent travel and destination management platform exclusively built for Kerala, India. It combines modern web technologies (Django, PostgreSQL, Bootstrap 5) with data analytics (Pandas, NumPy, Scikit-learn) and interactive geospatial mapping (Leaflet, OpenStreetMap) to provide tourists with an end-to-end trip planning and recommendation solution.

Technology Stack

Backend: Python Django & PostgreSQL
Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
Mapping: Leaflet, OpenStreetMap & Geolocation
Analytics: Scikit-learn, Pandas, Chart.js
